生成图以用户原创设计为参考，保留米白、番茄红、青菜绿、购物篮黄、信号蓝与手写黑色笔触。场景使用真实材质、低饱和暗部和克制灯光，以适配作品集的暗色档案风格；不新增品牌标志，不生成大段文字，不替代原创设计。
