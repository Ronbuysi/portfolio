# 兰木乡富硒米包装项目作品集设计说明

## 1. 目标

将用户提供的「兰木乡富硒米」包装设计整理为作品集中的第二个真实项目。项目应同时呈现最终样机、品牌视觉系统、包装结构与设计推演，避免只展示成品图或把整张设计展板缩小后直接放入页面。

项目类型统一标注为 `Packaging Design`，不展示未确认的项目年份、客户属性或商业成果。

## 2. 项目理解

这是一套面向东兰县兰木乡特色富硒米的包装系统，包含：

- 袋装礼盒样机与袋装刀版；
- 米砖腰封样机与腰封刀版；
- 天地盒外包装、内部支撑与结构示意；
- 完整设计展板；
- 包装延展与平面视觉应用。

视觉语言以地域农耕文化为核心。设计通过土地、稻穗、劳作人物与米粒/山形辅助图形建立产地联想，并将这些元素应用到不同包装结构中。

## 3. 视觉系统提取

网页不从展板中生成新的图形，也不重绘原作品。展板信息通过网页排版重新组织：

- 主棕色：`#9B6C43`；
- 主米白：`#FDF7E5`；
- 辅助色：由谷物金到暖白的低对比渐变；
- 元素叙事：`春种 / 夏长 / 秋收 / 冬藏`；
- 品牌口号：`真材实料 米有烦恼`；
- 项目关键词：地域、天然、农耕、环保、包装系统。

展板中提到可降解纸盒材料。网页将其表述为设计理念，不宣称已经量产或通过环保认证。

## 4. 在作品集中的位置

项目作为 `Selected Work / 002`，位于运营视觉设计之后、个人优势模块之前。

整体网站保持暗黑编辑部风格。包装项目内部使用米白、棕色与暖金建立一个短暂的“材质章节”，形成与项目 001 高饱和海报不同的情绪，但版心、字号层级、项目编号与元数据结构保持一致。

## 5. 项目内容顺序

### 5.1 项目标题与元数据

- 中文标题：`包装设计`；
- 英文标题：`Lan Mu Xiang Rice Packaging System`；
- 类型：`Packaging Design`；
- 范围：`Brand Visual / Dieline / Mockup`；
- 项目编号：`002`；
- 年份：不展示。

项目介绍文案：

> 面向东兰县兰木乡特色富硒米建立的包装系统。设计从地域农耕文化与水稻生长过程提取视觉线索，以米白、棕色和暖金构成自然质朴的品牌气质，并将统一语言延展至袋装礼盒、米砖腰封与天地盒结构。

### 5.2 样机封面

使用 `大米袋装样机最终版.jpg` 作为全宽项目封面。图片保持原始比例，不裁掉包装主体；桌面端允许使用轻微边距和暖色底板，使其与暗色网站自然过渡。

### 5.3 品牌语言与四季元素

建立一个网页原生信息模块，不生成新的作品图：

- 左侧展示品牌口号与项目背景；
- 右侧展示三个配色圆形色样；
- 下方以四格表达 `春种 / 夏长 / 秋收 / 冬藏`；
- 说明这些阶段对应展板中的牛、农人、稻田、收割与运输元素。

### 5.4 包装系统与结构

- 米砖样机作为横向大图，强调同一品牌视觉在小体量包装上的适配；
- 袋装刀版与天地盒刀版组成两列结构档案；
- 腰封包装刀版作为全宽长图，展示系列化视觉与尺寸落地；
- 所有刀版图使用 `object-fit: contain`，不可裁掉尺寸标注。

### 5.5 完整展板总结

项目末尾使用 `70a0461beb59d21d5f28c68af1ed7c88.jpg` 展示完整设计展板。展板作为“设计总结”出现，不承担主要阅读内容。旁边配一段简短说明，强调视觉、结构和延展之间的一致性。

## 6. 数据与组件调整

在 `projects` 数据中新增包装项目，并为项目提供可选展示字段：

- `theme`: `dark` 或 `warm`；
- `year`: 可选；
- `scope`: 项目范围；
- `gallery`: 图片、替代文本、展示角色与适配方式；
- `brandSystem`: 可选的配色与四季叙事数据。

`SelectedWork` 继续负责项目循环与共同标题结构。包装项目的专用内容拆成 `PackagingStory` 组件，负责品牌系统、结构档案与展板总结。这样后续增加普通项目时，不需要携带包装专用字段或条件分支。

## 7. 图片与性能

六张包装图片复制到 `public/images/packaging/`，不依赖桌面原路径：

1. `bag-mockup.jpg`；
2. `brick-mockup.jpg`；
3. `bag-dieline.jpg`；
4. `box-dieline.jpg`；
5. `band-dieline.jpg`；
6. `design-board.jpg`。

原图分辨率较高。基础版保留足够清晰度，同时将网页副本压缩到合理文件大小；桌面原文件保持不变。首张封面优先加载，其余图片使用懒加载并设置尺寸比例，避免滚动时布局跳动。

## 8. 响应式与可访问性

- 桌面端品牌语言与展板总结使用双栏布局；
- 小于 1100px 后结构档案改为单栏或两列自适应；
- 小于 720px 后所有包装图片改为单栏，刀版保持完整可读；
- 每张图提供描述其内容的中文 `alt` 文本；
- 配色信息同时显示色值，不能只用颜色传达；
- 暖色章节中的文字与背景保持可读对比度。

## 9. 测试与验收

- 数据测试确认项目总数为 2，包装项目不包含虚构年份；
- 组件测试确认包装标题、英文标题、六张图片、三种色值与四季元素均存在；
- 原有运营项目的四张图片和文案继续通过测试；
- `pnpm test` 与 `pnpm build` 成功；
- 1440px 与 1920px 桌面视口无横向溢出；
- 包装样机不变形，刀版尺寸信息不被裁切；
- 720px 视口不产生横向滚动；
- 浏览器控制台无资源加载错误。
