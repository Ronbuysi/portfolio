# 个人肖像替换设计规格

## 目标

使用用户提供的最新个人照片替换 About 模块现有肖像，并保持作品集冷静、暗色、科技档案式视觉。

## 处理原则

- 保留原始人物身份、五官、发型和服装，不进行 AI 改脸或人物重绘。
- 使用 CSS 完成 3:4 裁切、冷蓝单色、对比度与亮度控制。
- 保留现有细网格、磨砂职业标签和档案式说明。
- 桌面端焦点位于人物眼睛及头发轮廓；移动端小尺寸仍能清晰识别人脸。
- 不公开手机号码，不增加新的个人敏感信息。

## 资产与实现

- 新资产：`public/images/profile/wang-chengcheng-2026.jpg`
- `About.jsx` 更新图片路径和原始尺寸属性。
- 桌面裁切使用 `object-position: center 30%`。
- 移动裁切使用 `object-position: center 27%`。
- 冷蓝滤镜降低过强暖黄光，并保留皮肤与头发层次。

## 验收标准

- About 页面仅出现一张肖像。
- 图片路径为新资产，alt 文本保持可访问。
- 桌面 320px、平板 240px、移动 112px 宽度规则不变。
- 3:4 框架、冷蓝叠色、网格与磨砂标签继续生效。
- 自动化测试、构建与预览检查通过。
