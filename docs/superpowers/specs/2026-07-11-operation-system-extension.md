# 运营视觉系统延展规格

## 目标

在保留三张菜市场主题原始海报的基础上，把运营视觉扩展为现场导视和数字传播两套可持续使用的系统，避免项目只呈现海报画廊。

## 延展内容

- `operation-market-activation.png`：深色菜市场空间中的摊位头牌、吊旗、导向牌、价签、周转箱标签、托特包和地面导视。只保留 `GO`，其他文字区使用非语言笔触与蔬果图形。
- `operation-digital-system.png`：四张社交方图、三张竖版模板、横幅、贴纸条和移动端卡片组成的模块化传播系统。

## 页面结构

- 原三张海报继续标注 `ORIGINAL ARTWORK`。
- 新建运营项目专属 `OperationStory`，在原作后增加 `CAMPAIGN GRAMMAR`、现场激活和数字传播两节。
- 两张新图标注 `AI-ASSISTED CAMPAIGN EXTENSION`，保持 16:9。
- 品牌色与笔触只存在于运营项目内部，移动端单列。
