# 克制磨砂玻璃系统规格

## 目标

为整个作品集增加高级、克制的磨砂玻璃层级，同时保持作品图片、项目大标题和酸性绿联系页的清晰度。玻璃不能成为通用卡片模板，也不能在大面积滚动区域滥用昂贵模糊。

## 设计选择

- 一级玻璃：导航、圆角按钮。透明度高、模糊 16—18px，用于悬浮感。
- 二级玻璃：项目元数据、图片内说明条、AI 来源标签。深色半透明、细白边和顶部高光。
- 三级实色：原始作品、海报、AI 场景、品牌 DNA 大色块与 Contact 页全部保持实色。
- 使用统一 CSS 变量控制背景、边线、高光和模糊；提供 `@supports` 回退。
- 关闭透明效果的系统偏好下提高背景不透明度；移动端降低模糊强度。

## 验收

- Header、主要按钮、项目元数据和场景标签具有统一玻璃语言。
- 原作图片不加玻璃蒙层；Contact 仍为纯酸性绿。
- 无横向溢出，文本对比度可读。
- 测试、构建及桌面/移动端浏览器检查通过。
