# 王程程个人作品集网站设计说明

## 1. 项目目标

为视觉设计师、AI 设计师与品牌设计师王程程搭建一个适合 PC 端展示的个人作品集基础版。网站应呈现暗色、高级、克制、科技感强但不模板化的视觉气质，并为后续持续补充项目图片、参考截图和真实视频素材保留清晰扩展位。

基础版使用 React + Vite 实现，页面最大版心约 1700px，优先保证 1440px 至 1920px 桌面屏的体验，同时提供可用的平板和移动端降级布局。

## 2. 已确认的视觉方向

采用 A「暗黑编辑部」为主视觉方向，并吸收 B「冷调电影感」的全屏动态氛围：

- 主色为近黑、石墨灰和暖白，使用酸性荧光绿作为小面积高亮色。
- 通过巨型无衬线字体、不对称网格、项目编号和横向作品编排建立编辑感。
- 避免大面积玻璃拟态、赛博霓虹和常见模板式渐变卡片。
- 使用细边线、低对比噪点、局部光晕和克制的滚动动效表达科技感。
- 运营设计海报保持原有高饱和色彩，网站框架负责衬托作品，不改变作品本身。

## 3. 隐私与公开信息

- 不展示手机号码。
- 不使用简历证件照。
- 公开邮箱 `241022998@qq.com` 作为主要联系入口。
- 人物区域使用抽象图形、字母排版与经历信息构成，不模拟真实人物形象。

## 4. 页面结构

### 4.1 全屏 Hero

- 高度为一个完整视口。
- 顶部导航包含姓名标识、Work、About、Contact 和强调式联系按钮。
- 主标题使用 `VISUAL DESIGNER.`，辅助身份为 `VISUAL × AI × BRAND`。
- 使用本地 MP4 作为背景视频；基础版由暗色抽象视觉制作低速动态视频。视频加载失败、系统减少动态效果或小屏设备时，回退到静态封面和 CSS 光晕。
- 提供向下浏览精选项目的明确入口。

### 4.2 个人经历

- 左侧为不含人物肖像的抽象字母视觉，右侧为个人介绍与经历摘要。
- 介绍文案：王程程，视觉设计师与 AI 设计实践者，视觉传达设计本科，设计学硕士在读，关注品牌视觉、运营设计与生成式 AI 在创意流程中的融合。
- 时间线包括广西民族大学视觉传达本科、沈阳建筑大学设计学硕士在读、成华教育助教与平面设计相关实习。
- 数据展示使用 `3 项核心方向`、`3 项设计奖项`、`2020—NOW 设计旅程`，避免夸大商业项目数量。
- 展示公开邮箱，不展示手机号。

### 4.3 精选项目

- 首个真实项目组暂定名为「运营视觉设计 / Farmers' Market Campaign」。
- 项目封面使用 imagegen 生成的暗色展陈视觉，作为网站暗色框架与高饱和海报的过渡。
- 项目卡片展开区域展示用户提供的三张原始海报，保持原始比例、文字和色彩，不进行重绘或裁切破坏。
- 项目元数据使用角色、类别、年份和工具字段；不编造客户、商业成果或未提供的职责。
- 后续新增作品时，通过项目数据数组扩展，不修改页面结构。

### 4.4 个人优势

使用四张等宽卡片表达能力：

1. 视觉系统：色彩、字体和版式的系统化设计。
2. 品牌表达：将概念转化为一致且有识别度的品牌视觉。
3. AI 共创：ChatGPT、Midjourney、Gemini、Claude 等生成式工具融入创意流程。
4. 动态叙事：使用 AE 等工具扩展静态视觉的时间维度。

软件能力包括 Illustrator、Photoshop、After Effects、InDesign 与 Office/WPS，但不把软件列表作为能力模块的唯一内容。

### 4.5 整屏联系方式

- 使用荧光绿整屏作为页面收尾，与前文暗色形成强烈但克制的反差。
- 大标题为 `LET'S MAKE SOMETHING MEMORABLE.`。
- 邮箱点击后使用 `mailto:` 打开邮件客户端。
- 提供返回顶部入口和版权信息。

## 5. 内容与组件架构

- `App`：页面组合与全局交互入口。
- `Header`：固定或半透明导航、锚点跳转和联系按钮。
- `Hero`：视频、静态回退、主标题与滚动提示。
- `About`：抽象视觉、介绍、经历时间线和数据。
- `SelectedWork`：项目封面、项目元数据和海报画廊。
- `Strengths`：能力卡片列表。
- `Contact`：整屏联系区与页脚。
- `projects` 数据文件：保存项目标题、图片、年份、分类和说明，为后续增补内容提供单一入口。

页面为单页结构，导航使用锚点滚动，不引入路由和后台管理。组件边界以内容职责划分，避免单文件承载全部界面。

## 6. 动效与交互

- 首屏标题与导航在加载后做短时淡入和位移。
- 项目卡片在悬停时轻微放大图片并显示项目元数据，不使用强烈 3D 翻转。
- 能力卡片使用边框、编号和背景亮度变化表达状态。
- 页面滚动采用原生平滑锚点；基础版不引入重型动画库。
- 支持 `prefers-reduced-motion`，减少动画时关闭自动位移、缩放和背景视频播放。

## 7. 错误处理与降级

- 视频不可播放时显示静态封面与暗色渐变。
- 图片使用明确的 `alt` 文本，并设置合理的 `object-fit` 和背景色避免布局跳动。
- 邮箱为唯一公开联系渠道；不产生无后端支持的联系表单。
- 素材缺失时项目数据允许显示封面和说明，不显示空白卡片。

## 8. 技术实现

- React 组件与 Vite 构建。
- 原生 CSS 变量和响应式网格，不引入 UI 组件库。
- 使用项目本地图片和视频资源，避免依赖第三方素材 URL。
- 版心使用 `min(1700px, calc(100vw - 64px))`，在较小屏幕逐步收窄边距。
- 字体优先使用本机可用的现代中文无衬线与英文 grotesk 字体栈，不依赖远程字体才能正常显示。

## 9. 验收标准

- `npm run build` 成功且无编译错误。
- 本地开发服务器可打开，页面包含五个已要求模块。
- 1440px 与 1920px 桌面视口下无横向溢出、文字遮挡和图片拉伸。
- 项目封面与三张海报均能正常显示。
- 导航锚点、联系邮箱和返回顶部功能可用。
- 视频具备静态回退，减少动态偏好得到尊重。
- 不公开手机号，不显示证件照，不编造未提供的商业项目和成果。

## 10. 后续扩展

后续可以在不改变整体结构的前提下补充品牌设计、AI 设计和其他视觉项目，替换 Hero 视频，并根据参考网站继续调整字体、动效、卡片比例和项目详情呈现。
