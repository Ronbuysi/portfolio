# 酸嘢信息设计与三福节点延展规格

## 目标

1. 精简三福原创证据模块，移除整张包装展版。
2. 将三福 `9.1 / 10.1 / 520` 三个数字拼图发展为更具体的节点应用。
3. 在豪士面包之后新增独立的“酸嘢信息可视化设计”项目，将两张原创海报扩展为完整的信息设计案例。

## 三福调整

- 原创证据由六项减为五项：旅行、宿舍、职场海报，元素系统，数字系统。
- `original-packaging.jpg` 不再进入页面 DOM。
- 新增两个 Image-2 延展：数字节点橱窗装置、节点会员礼赠与传播卡。
- 原有包装系统继续作为节点包装家族展示，与新增资产形成“包装 / 空间 / 传播”三层应用。

## 酸嘢信息设计定位

- 项目名称：酸嘢图鉴
- 英文名：Suan Ye Information Visualisation
- 分类：Information Design
- 位置：豪士成长日常之后
- 叙事重点：将地域、食材、口味、制作流程和摊位文化组织成可读、可扩展的信息系统。

## 可提取视觉元素

- 荧光浅绿背景与深绿主文字
- 黄、橙、蓝作为水果和流程强调色
- 水果切面、多边形食材和夸张酸味表情
- 酸 / 辣 / 咸 / 甜四类情绪角色
- 广西分布地图、金字塔、环形占比、时间流程线
- 路牌、三轮车、水车、市集摊位等地域场景插画

## Image-2 延展资产

生成五张新图：

1. 信息设计展览 Hero：暗色展厅中由荧光绿信息面板、地图和水果角色组成的模块化展览。
2. 酸味角色系统：六个水果角色的统一建模与表情矩阵。
3. 市集导视系统：摊位、菜单、价签、路牌和包装的完整场景。
4. 数据卡与出版物：信息卡、折页、图鉴、食材标签与流程卡的静物系统。
5. 数字交互界面：地图筛选、口味占比、制作流程和水果档案的屏幕系统。

准确中文标题与说明由 HTML/CSS 输出；生成图避免大段不可读文字、虚构品牌 logo 和水印。

## 新项目结构

1. Hero：AI 辅助的信息展览场景。
2. Information Architecture：地域、种类、口味、流程四层结构。
3. Original Evidence：两张原创信息海报完整展示。
4. Visual Grammar：颜色、图形、角色和图表语言。
5. Extension System：角色、市集、出版物与数字界面四组应用。
6. Outro：以荧光绿完成整屏信息结论。

- 新建 `InformationStory.jsx`，不复用通用海报组件。
- `SelectedWork.jsx` 增加 information 路由和样式类。
- 三福 `extensions` 增加两个节点资产，`originalEvidence` 删除包装展版。

## 验收标准

- 三福页面不再渲染 `original-packaging.jpg`。
- 三福原创证据数量为五，AI 延展数量为八。
- 酸嘢项目位于豪士项目之后，品牌项目和 IP 项目之前。
- 酸嘢两张原创海报各出现一次，并至少展示五张 Image-2 延展。
- 页面项目总数为七，编号连续为 001-007。
- 桌面端对齐，移动端单列且无横向溢出。
- 自动化测试、生产构建和资源响应检查通过。
