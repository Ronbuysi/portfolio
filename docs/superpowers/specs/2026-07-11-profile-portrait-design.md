# 个人照片模块设计规格

## 1. 目标

将用户明确授权的个人照片加入 `About` / 个人经历模块，替换现有 W/C/C 抽象字形。人物必须保持真实，不进行生成式重绘或五官修改，并继续隐藏手机号。

## 2. 已确认方向

- 视觉方向：方案 3，高对比深海军蓝 / 灰白双色调。
- 原图：`3a408e3e3fc2490b4d6959f6ee2fd6be.jpg`。
- 保留脸部、眼镜、服装和构图；不磨皮、不改变人物身份。
- 使用确定性的 CSS 灰度、对比度和深蓝混合处理，使暖色商场背景融入暗色作品集。
- 酸性绿只用于细线、坐标和小标签，不覆盖面部。

## 3. 布局

- 桌面端沿用 About 两列骨架，左侧为大幅竖版人物图，右侧为介绍、项目数据、经历和邮箱。
- 人物图与右侧内容在同一顶部基线；图片保持竖版比例，使用 `object-fit: cover`，焦点偏上以保护脸部。
- 图片上增加细网格、编号、`VISUAL / AI / BRAND` 和 `PROFILE / WANG CHENGCHENG` 等非敏感标签。
- 移动端人物图位于文字前，缩短高度但不隐藏。

## 4. 隐私与真实性

- 页面不出现手机号。
- 只使用用户本次上传并明确授权的照片。
- 不用 image-2 重绘本人；视觉融合由 CSS 完成。
- 图片 alt 使用中性描述，不包含联系方式。

## 5. 验收

- About 中存在且仅存在一张授权人物图。
- 人物图有有效 alt，源文件被复制到稳定的 `public/images/profile/` 路径。
- 桌面与移动端均不变形、不遮挡面部。
- 原有履历、荣誉、项目数据和邮箱保留。
- 内容与 DOM 中均无中国大陆手机号格式。
